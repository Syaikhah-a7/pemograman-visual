# pemograman-visual pert. 1

-Pemograman visual adalah cara membuat tampilan UI suatu aplikasi bukan dengan membuat kode tetapi dengan komponen-komponen yang tampak langsung perubahannya.
-Jika pemograman biasa memerlukan proses run untuk melihat perubahannya, maka pemograman visual tidak. Kita bisa menulis kode dan juga mendesain aplikasi menggunakan komponen seperti Button, TextBox, Label, dll.
-Sesudah tampilan selesai dibuat, kita harus membuat kode agar masing-masing komponen dapat berfungsi ketika berinteraksi dengan pengguna.
-Di mata kuliah ini, kami menggunakan Visual Basic sebagai bahasa pemrograman, Visual Studio sebagai IDE atau tempat untuk membuat program, dan .NET sebagai platform yang menyediakan berbagai fasilitas untuk membangun dan menjalankan aplikasi.
