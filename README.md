## Pertemuan 1 - Pengenalan Pemograman Visual
 
Pemograman visual adalah cara membuat tampilan UI suatu aplikasi bukan dengan membuat kode, tetapi dengan komponen-komponen yang tampak langsung perubahannya.
 
Jika pemograman biasa memerlukan proses run untuk melihat perubahannya, maka pemograman visual tidak. Kita bisa menulis kode dan juga mendesain aplikasi menggunakan komponen seperti Button, TextBox, Label, dll.
 
Sesudah tampilan selesai dibuat, kita harus membuat kode agar masing-masing komponen dapat berfungsi ketika berinteraksi dengan pengguna.
 
Di mata kuliah ini, kami menggunakan **Visual Basic** sebagai bahasa pemrograman, **Visual Studio** sebagai IDE atau tempat untuk membuat program, dan **.NET** sebagai platform yang menyediakan berbagai fasilitas untuk membangun dan menjalankan aplikasi.

## Pertemuan 2 - Komponen Visual
 
Pada pertemuan ini, materi berfokus pada pengenalan dan penggunaan **komponen-komponen visual (control)** dalam Visual Studio untuk membangun antarmuka aplikasi Windows Forms.
 
Beberapa komponen dasar yang dipelajari antara lain:
 
- **Form** — jendela utama tempat komponen-komponen lain diletakkan.
- **Label** — menampilkan teks statis kepada pengguna.
- **TextBox** — menerima input teks dari pengguna.
- **Button** — memicu suatu aksi atau event ketika diklik.
Setiap komponen memiliki **properti** (seperti Name, Text, Size, Location) yang dapat diatur langsung melalui jendela Properties di Visual Studio, tanpa perlu menuliskannya sebagai kode terlebih dahulu. Selain itu, tiap komponen juga memiliki **event** (misalnya Click, TextChanged) yang dapat diberi kode agar komponen tersebut merespons interaksi pengguna.
